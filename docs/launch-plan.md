# Build and launch decision — 26 September 2026

Develop the free local client first; make an actual installation and useful evidence block the acquisition asset. A website or registry listing alone does not supply active customers. The public source repository is https://github.com/rfzj4ygm68-cyber/researchblocks. No package registry listing, promotional campaign or paid execution has been created by this release.

## Commercial implementation adjustment

Do not base hosted margins on reselling a finished research provider's output. Parallel's application permission coexists with restrictive resale and reuse clauses; the optional adapter is local and caller-funded. See provider-review.md. Free client use is not a blanket exemption from supplier terms.

The next hosted candidate is **Serper discovery plus our own official-source processing and comparison assembly**. Its terms prohibit unchanged mirroring, contemplate end users, and preserve source attribution and third-party rights. This supports investigating a value-added application, not an unrestricted resale licence or legal assurance. Source-fetching and model-provider permissions still matter.

Serper's published starter bundle is $50 for 50,000 queries, with six-month credit expiry and taxes excluded. At full utilisation, six searches are $0.006. This is discovery cost only: fetches, extraction/model calls, failures, payment settlement and hosting remain to be measured. Trial credits are not sustainable unit economics. No account or credit purchase was made.

## Concrete next implementation

1. Finish a caller-owned provider trial with an authorised key and bounded spend. Measure real completion, evidence quality and invoiced cost, separately from synthetic verification.
2. Build the hosted discovery/source-processing worker on commercially suitable services. Keep per-customer evidence private. Add authorisation, quotas, billing reconciliation, durable task recovery and a real hard service budget before taking payments.
3. Exercise the MCP package in two real agent clients and improve any installation friction.
4. The public repository includes the local package, installation recipe and complete agent skill. Package-registry availability and directory submissions remain unverified. Publication is not evidence of installations or active users.
5. Distribute through relevant skill/MCP directories using their genuine submission routes; then submit a working framework example. Operator-facing promotion should demonstrate what an agent actually receives.

A hosted paid service is not yet implemented. The prototype does not earn money merely by being installed. The saleable proposition remains reliable bounded research work and delivery, evaluated against the caller's usual tools.

## Release positioning

Describe this accurately as an alpha local comparison-evidence toolkit with an optional unverified-live BYOK adapter. Offer the zero-cost offline demo and the source-backed imported example. Do not present either as an independently purchased research job or claim a speed/accuracy advantage without measurement.

Track activated integrations, later distinct completed jobs, and repeat paid use when available. Do not convert package downloads, fixture runs, searches or source views into customer counts. Local usage is unavailable without explicit opt-in telemetry.

Working planning milestones remain 20 activated integrations, 5 returning and 3 paying, not market benchmarks. The prior 0.25 USDC price and 0.10 cost assumption remain hypotheses until the hosted implementation is measured.
